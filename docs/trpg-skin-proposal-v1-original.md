# 티스토리 스킨 디자인 제안서: TRPG & OC 유저를 위한 '개인 홈페이지' 스킨

## 1. 프로젝트 개요
* **목표:** TRPG 플레이어 및 시나리오 라이터의 니즈를 충족하고, 기존 티스토리 블로그의 형태를 벗어나 개인 홈페이지(갠홈) 감성을 내는 미니멀하고 모던한 스킨 제작.
* **기술 스택:** 바닐라 HTML / CSS / JS (외부 라이브러리 최소화)
* **개발 핵심 철학:** 코드를 먼저 짜지 않고, 유저의 체감과 접근 경로(UI/UX)를 최우선으로 설계할 것. 복잡한 스킨 옵션을 배제하고 직관적인 조작감을 제공한다.

## 2. 티스토리 기본 요소 통제 및 카테고리 라우팅
이 스킨의 핵심은 '티스토리 블로그'처럼 보이지 않는 것입니다.
* **기본 UI 숨김 처리:** 티스토리 특유의 공감(하트) 버튼, 기본 댓글창, 구독하기 버튼, 하단 Powered by, 방명록, 우측 상단 기본 툴바 등을 CSS/JS로 완전히 숨기거나 스킨 톤앤매너에 맞게 극도로 미니멀하게 개조해야 합니다.
* **라우팅 설정 방식:** 유저가 스킨 편집(옵션) 창에서 `캐릭터 카테고리`, `시나리오 카테고리`, `로그 카테고리`의 이름을 지정하면, 스킨이 이를 감지하여 해당 카테고리 접속 시 전용 템플릿 CSS/JS를 출력합니다.

## 3. 핵심 기능 및 UX/UI 명세서

### 3.1. 모듈형 블로그 홈 (Home Cover)
* **UX/UI:** 티스토리 홈 커버(Cover) 기능을 활용하여, 유저가 블록 장난감처럼 원하는 섹션만 골라 순서를 배치할 수 있게 합니다.
* **구현 방식:** 스킨 옵션에서 `[시나리오 갤러리형]`, `[캐릭터 리스트형]`, `[로그 썸네일형]`, `[텍스트 공지사항]` 등의 구조 프리셋(모듈)을 제공하여, 유저의 취향에 따라 자유롭게 홈 화면을 구성하도록 설계합니다. (세부 디자인 컨셉은 별도 부록 문서 참고)

### 3.2. 로그 백업 UX (첨부파일 렌더링 방식)
* **문제점:** 긴 HTML 코드를 티스토리 에디터에 붙여넣을 때 발생하는 심각한 렉과 튕김 현상.
* **해결책:** 유저는 본문에 코드를 복사할 필요 없이, 롤20/코코포리아에서 추출한 HTML/TXT 파일을 게시글에 **'파일 첨부'**만 하고 발행합니다.
* **작동 방식:** 프론트엔드(JS)에서 첨부파일의 데이터를 읽어와 화면에 깔끔한 채팅 로그 UI로 렌더링합니다. (참고: factory-roll20-machine 사이트 UI)

### 3.3. 시나리오 라이터를 위한 본문 가독성 템플릿
* **목표:** 플레이어(로그)뿐만 아니라, 시나리오 라이터가 쾌적하게 글을 쓰고 읽을 수 있는 '소설 내지' 수준의 가독성 확보.
* **디자인 요소:**
    * 타이포그래피 정비 (적절한 줄 간격, 자간, 명확한 문단 구분).
    * TRPG 시나리오 작성에 특화된 미니멀한 인용구, NPC 대화창, 핸드아웃 삽입용 CSS 클래스 제공.
    * 우측 상단 스위칭 버튼을 통한 **그리드 뷰(썸네일 중심)**와 **리스트 뷰(정보 중심)** 홈 전시 기능.

### 3.4. 캐릭터 및 관계 전시 (1~4인 레이아웃 템플릿)
* **캐릭터 갤러리:** 캐릭터 카테고리 클릭 시 증명사진(두상/흉상) 갤러리가 노출되며, 클릭 시 상세 게시글로 이동.
* **게시글 내 필수 정보란:** 캐릭터 이름, 소속, 출신 룰, 다녀온 시나리오, 등장 로그 링크.
* **다인(1~4인) 페어 템플릿:** 유저가 에디터에서 최소한의 텍스트와 이미지만 넣어도 CSS(타로카드 프레임, 찢어진 종이 등)가 씌워지도록 극도로 단순화된 HTML 마크업 양식을 제공.

### 3.5. TRPG/갠홈 과몰입 특화 기믹 (핵심 셀링 포인트)
1. **보호글/비밀글 컨셉 연출:** 실제 티스토리 비밀글 기능을 유지하여 검색/노출을 차단하되, 비밀번호 입력 화면을 "이 세션의 진상을 열람하시겠습니까?" 등 TRPG 감성에 맞춘 컨셉 UI로 덮어씌웁니다.
2. **이중 프로필 및 비밀(Secret) 플립 효과:** 증명사진이나 텍스트에 Hover 시 반전(Flip)되거나 숨겨진 이면의 설정이 나타나는 CSS 효과.
3. **스포일러 블라인드:** 본문 내 특정 텍스트를 가리는 `█████` 인라인 CSS 지원 (클릭/드래그 시 해제).
4. **접힘글(더보기) 커스텀:** 티스토리 기본 '더보기' 텍스트를 스킨 옵션에서 2가지 테마([경고형 ⚠️], [미니멀 실선형])로 선택 변경할 수 있게 지원.
5. **호버(Hover) 반응형 연출:** 과도한 장식을 배제하고 미니멀리즘을 유지하며, 아래 레퍼런스를 참고하여 Hover 액션 시 몰입감을 주는 CSS 인터랙션을 설계합니다.
    * [Colorion Text Effects](https://kinetics.colorion.co/?ref=text-effects.colorion.co)
    * [UIverse Elements](https://uiverse.io/elements)
    * [CanvasUI VHS](https://canvasui.dev/docs/components/vhs)

## 4. Claude(AI) 작업 시 주의 및 지시사항
* **에디터 의존도 낮추기:** 유저가 HTML 모드에서 복잡한 코드를 치지 않게 설계하십시오.
* **디자인 톤앤매너:** 불필요한 테두리, 그림자, 설명 텍스트를 배제하고 여백과 Z-index 교차를 활용한 '미니멀리즘'을 유지하십시오.
* 이 문서를 바탕으로 먼저 **'로그 백업 첨부파일 렌더링 스크립트'**의 구상과 **'전체 CSS 레이아웃(그리드/템플릿) 마크업 구조'**를 제시하십시오.
