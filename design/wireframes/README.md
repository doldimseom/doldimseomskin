# 와이어프레임 작업 파일

TRPG 향유층 갠홈 스킨의 화면 와이어프레임 v1 (저충실도 흑백).

- `*.dc.html` — 아트보드 1개 = 화면 1개
- `canvas.json` — 배치·주석·시작 화면
- `trpg-skin-wireframes.html` — 위 파일들을 묶어 발행한 결과물

수정은 `.dc.html`을 고친 뒤 다시 묶어 같은 주소로 올린다.

| 파일 | 화면 |
| --- | --- |
| `Main.dc.html` | WF-01 캐릭터 증명사진 갤러리 (데스크탑) |
| `CharacterDetail.dc.html` | WF-02 캐릭터 개별 페이지 — 세로 1단 |
| `CategoryList.dc.html` | WF-03 그 외 카테고리 카드 목록 |
| `HomeCover.dc.html` | WF-04 홈 커버 — 모듈 4종 |
| `Lightbox.dc.html` | WF-05 갤러리 뷰어 (라이트박스) |
| `RelationGraph.dc.html` | 관계도 A안 — 노드 그래프 |
| `RelationCards.dc.html` | 관계도 B안 — 관계 카드 리스트 |
| `MobileGallery.dc.html` | WF-01M 모바일 갤러리 |
| `MobileDetail.dc.html` | WF-02M 모바일 개별 페이지 |
